# dsh-quick-prompts

给 DeepSeek Harness（DSH）的输入框加上快捷指令：敲 `/缩写` 回车，把预设好的一段文本追加到草稿，常用的提示词不用每次手打。

## 它做什么

| 层 | 能力 |
|---|---|
| 斜杠展开 | 输入框敲 `/` 弹出指令菜单，选中或敲完缩写回车即展开 |
| 配置卡 | 在插件管理页增删改指令、模拟调用、查看每条指令的调用次数 |
| 列表 | 按字母、添加时间或修改时间排序，长文本可展开查看 |

## 安装

DSH 桌面版：插件管理 → 添加插件 → 输入仓库地址 `https://github.com/sadjjk/dsh-quick-prompts` → 确认。

## 使用

1. 在对话输入框敲 `/`，从菜单里选一条指令，或直接敲 `/check` 这样的完整缩写后回车。
2. 展开的文本追加到草稿；按「回车行为」设置决定立即发送，还是留在草稿里接着改。
3. 打开插件管理页里本插件的配置卡，可以添加自己的指令：缩写（`/` 后的触发词）、显示名（选填）、展开文本。

首次安装自带 6 条通用指令，可随意修改或删除：

| 缩写 | 名称 | 用途 |
|---|---|---|
| `check` | 谋定后动 | 不附和，先检查前提，区分事实与推测 |
| `start` | 开工确认 | 改代码前先复述需求、列文件、划边界 |
| `restate` | 需求复述 | 先复述目标与痛点，不给方案 |
| `example` | 对比举例 | 用真实数据举例，展示改前改后 |
| `wait` | 等一等 | 先分析，等确认 |
| `review` | 收尾复盘 | 找出没做完、被遗漏或有风险的事 |

## 设置

| 设置 | 说明 |
|---|---|
| 回车行为 | 追加后发送（默认）：展开后立即发送；追加到草稿：展开后留在草稿（末尾带空格），方便接着改 |

指令列表与调用次数保存在 `~/.dsh/dsh-quick-prompts/data.json`。该文件损坏（不是合法 JSON 或结构不对）时，插件会把它改名为 `data.json.corrupt-<时间戳>` 留在同一目录，再显示内置默认指令；需要找回时把备份改回 `data.json` 即可。

## 从 0.1.0 升级

数据目录从 `~/.dsh/quick-prompts/` 改为 `~/.dsh/dsh-quick-prompts/`，新版本不读旧路径。升级前先关闭插件，再移动数据文件：

    mkdir -p ~/.dsh/dsh-quick-prompts
    mv ~/.dsh/quick-prompts/data.json ~/.dsh/dsh-quick-prompts/data.json

不移动的话，新版本会显示内置默认指令；旧文件不会被改动，之后随时可以按上面的命令移过去（会覆盖新路径下已有的文件）。
